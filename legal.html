Política de Privacidad

Responsable del tratamiento

El responsable es Mariano Blanco Sanz, titular de Velsuna Web Studio. Puedes contactar en info@velsuna.com.

Qué datos tratamos

Esta web no dispone actualmente de formularios de registro ni crea cuentas de usuario. Si contactas voluntariamente por correo electrónico o WhatsApp, podremos tratar los datos que nos facilites, como nombre, datos de contacto, contenido del mensaje e información necesaria para preparar un presupuesto o prestar el servicio solicitado.

Finalidades

  • Atender consultas y solicitudes de información.
  • Preparar presupuestos y realizar actuaciones previas a una posible contratación.
  • Gestionar la relación profesional y administrativa cuando se contrate un servicio.
  • Cumplir obligaciones legales, fiscales y contables cuando proceda.
  • Proteger la seguridad y el correcto funcionamiento de los servicios utilizados.

Base jurídica

El tratamiento se basa, según el caso, en la aplicación de medidas precontractuales solicitadas por la persona interesada, la ejecución de una relación contractual, el cumplimiento de obligaciones legales y, cuando corresponda, el interés legítimo en mantener la seguridad y atender correctamente las comunicaciones recibidas.

Conservación

Los datos se conservarán únicamente durante el tiempo necesario para atender la finalidad para la que fueron facilitados y, cuando exista una relación contractual o una obligación legal, durante los plazos exigibles conforme a la normativa aplicable.

Destinatarios y proveedores

No vendemos datos personales. Podrán acceder a determinados datos proveedores tecnológicos necesarios para prestar el servicio, como servicios de alojamiento web, correo electrónico o comunicaciones, siempre dentro de sus funciones. También podrán comunicarse datos a autoridades u organismos públicos cuando exista obligación legal.

El sitio está alojado mediante GitHub Pages. El uso de este servicio puede implicar el tratamiento de datos técnicos necesarios para servir y proteger la página conforme a las condiciones del proveedor. Si eliges contactar mediante WhatsApp, pasarás a un servicio externo y se aplicarán también sus propias condiciones y política de privacidad.

Política de Cookies

Actualmente Velsuna Web Studio no utiliza herramientas propias de analítica, publicidad comportamental ni personalización que requieran la instalación de cookies no necesarias.

Cookies técnicas y servicios de infraestructura

La web se sirve mediante infraestructura tecnológica de terceros. Dichos proveedores pueden aplicar mecanismos técnicos estrictamente necesarios para seguridad, disponibilidad o prestación del servicio. Velsuna Web Studio no utiliza esos mecanismos para crear perfiles publicitarios de las personas usuarias.

Sin banner de consentimiento por ahora

Mientras no se incorporen cookies o tecnologías no exceptuadas que requieran consentimiento, no se mostrará un banner de aceptación. Si en el futuro añadimos analítica, publicidad, píxeles u otras tecnologías que necesiten consentimiento, esta política se actualizará y se implementará el mecanismo correspondiente antes de activarlas.

Cómo controlar las cookies

Puedes configurar tu navegador para bloquear, limitar o eliminar cookies. Ten en cuenta que bloquear determinados mecanismos técnicos podría afectar al funcionamiento de algunos servicios web.
